# Kiwi Systems

Kiwi’s websites, applications and Kiwi Commerce landing page. Standalone static site; no build step or backend required. Includes French, English and Arabic with RTL, reduced-motion support, responsive layouts and a clearly labelled illustrative COD order demo.

## Preview locally

Run `python3 -m http.server 8080` from this directory, then open http://localhost:8080.

## Hosting

GitHub Pages serves the `main` branch at its root. No Cloudflare deployment or configuration is used. All asset URLs are relative for GitHub project Pages compatibility.

## Contact

WhatsApp and email use Kiwi’s existing public contact details. Selecting a service prepares the relevant WhatsApp message; the visitor chooses whether to send it. The order demo uses local sample data and never connects to a merchant database.

## Brand

Uses Kiwi’s existing wordmark, scene poster, Inter Tight, green palette and Kiwi Commerce logo. No client names or client assets are included. Fonts load from Google Fonts with system fallbacks.
